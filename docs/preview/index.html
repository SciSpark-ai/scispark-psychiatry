How it works

A fixed pipeline. The model is used in four places, and code checks what it returns.

  1. RetrievePubMed queries built from your topics
  2. FilterPsychiatric papers kept, every drop logged
  3. GradeModel rates each match; quotes checked
  4. SummariseHeadline and summary, numbers checked
  5. Build the WikiEvidence map by condition and treatment

Checks on the model

  • Numbers must appear in the abstract
  • Summaries rest on a real abstract sentence
  • A sample size must count people
  • Association is not shown as benefit
  • Treatments matched to a term pack

Limits

  • An early build; not medical advice
  • One direction label per paper; no effect sizes
  • Counts only the papers your feed listed
  • Mostly abstracts, rarely full text
  • Do not enter patient information
  • Your model key is stored in plain text, locally

Run it locally

Needs Node.js 20.9+ and your own model provider key.

git clone https://github.com/SciSpark-ai/scispark-psychiatry.git
cd scispark-psychiatry
npm ci
npm run dev

Open http://127.0.0.1:3000 → connect your AI in Settings → add topics → press Refresh. Each refresh uses your key.
