# Third real run — 2026-10-06 (commit dadfe94)

Same setup. New: the quote check ignores closing punctuation and dash or apostrophe variants; the run log records
why an AI summary was not shown.

**Time.** 147 seconds (search 24 s, grading 65 s, list and summaries 52 s).

**Stage yields.** Retrieved 551, topic filter 490, design gate 419, graded 150, **listed 48 (the list is now
full)**, lower-confidence 30. No failed queries, no warnings.

**Grading.** 6 of 150 skipped by the model (run 2: 19). The model gave 73 positive grades; 12 were zeroed by the
quote check (run 2: 37 of 75). The five looked at are mid-sentence fragments that do not appear in the text as
written. Listed by entry: Schizophrenia 24, depression × esketamine 18, ADHD × methylphenidate 6.

**Stability, run 2 against run 3 (same code path for the cap).** 144 of the 150 graded papers were the same.
Of the 120 graded (not skipped) in both runs, the model gave the same grade to 61, and 21 flipped between zero
and a positive grade. 21 papers were listed in both runs (of 34 and 48). The main cause is the model giving a
different grade to the same paper, not retrieval.

**Summaries.** 37 of 48 shown. Dropped: 7 "quote not in abstract", 4 "number not in text" (0.74, 21,025, 8,679,
2.26). The number drops look like print conventions (0·74, 21 025); the check was changed after this run to
compare digits and is not yet measured.
